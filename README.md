# SQL Data Analytics Portfolio

## Project Overview
This repository contains SQL queries and practice exercises focused on data analysis, data exploration, and extracting meaningful insights from datasets.

It showcases my SQL skills and understanding of database querying techniques used in data analytics.

## Objectives
- Retrieve and analyze data using SQL.
- Filter, sort, and summarize datasets.
- Perform aggregations to analyze business data.
- Combine data from multiple tables.
- Identify trends and patterns using SQL queries.
- Improve problem-solving and analytical skills.

## SQL Concepts Covered
- SELECT, WHERE, ORDER BY
- DISTINCT, LIMIT
- GROUP BY and HAVING
- Aggregate Functions: COUNT, SUM, AVG, MIN, MAX
- CASE Statements
- Joins: INNER JOIN, LEFT JOIN, RIGHT JOIN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions: ROW_NUMBER, RANK, DENSE_RANK
- NULL Value Handling
